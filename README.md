# APCAS `2.1.1`

> [Take a live demo now!](https://apcasv211.streamlit.app)


APCAS stands for Any PDF Chatting AI System, it is basically a RAG (Retrieval Augmented Generation) based application, that optimized for chatting with any PDF in an efficint way, still it is not a professional project So it may have several bugs.



> [!NOTE]
> Your Ideas, Sugestions, Contributions always welcome 😃 here.


### Features of this APCAS version
- It is well optimized
- It is also open-source
- It provide these options to chat with PDF:
   - Chat with images only
   - Chat with only first page of PDF
   - Chat with entire PDF (_Images as well as Text_)


### Technologies used in this Project
- Version Control (Git & Github)
- Web Application (Using Streamlit)
- OOPs (Object Oriented Programming System)
- Python with its libraries and some more techs
- Langchain
  - Custom Retriever cosine similarity
  - OpenAI `GPT 4o mini`


### Older Versions (Live)

- [Version `2.0.0`](https://apcass2.streamlit.app) (Chat only with text)



### List of bugs/failure conditions (not resolved in this version)
- Failed if you provide any other document rather than a PDF.
- If you choose Images Only option but our model unable to extract a single image (reason: internal/external), error will occurred.
- Failed if your provided PDF contains:
   - Blank pages
   - Corrupt pages
